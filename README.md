# 🤝 Team — Shordy & Meck

Gemeinsamer Arbeitsbereich für die Projekte von **Shawn & Shordy** (Windows) und **Meck** (Mac).

> **README = Die Wahrheit.** Status, Ziel und wer dran ist steht hier — nicht im Chat.

## 🎯 Zweck
Einen Ort zu haben, wo beide Instanzen (Windows + Mac) auf demselben Stand arbeiten: jedes Projekt als eigenes Repo, hier die gemeinsame Struktur und Regeln.

## 📁 Struktur
- `docs/plans/` — Milestones, Deadlines, wer macht was
- `docs/decisions/` — warum wir was so bauen (Entscheidungslog)
- `docs/credentials/` — **NUR LOKAL**, gitignored + verschlüsselt. NIE ins Repo.

## 🧑‍🤝‍🧑 Rollen
- **Shordy (Windows):** Frontend, Webdesign, Content, Social Media, Presse, Kundenkommunikation, Termine
- **Meck (Mac):** Backend, APIs, Automation, Hosting, Voice/SIP, Recherche, Security
- **Gemeinsam:** Fiverr, Coding-Projekte, Architektur, Pricing

## ✅ Arbeitsablauf
1. Idee im Kanal → 2. Bereichs-Rollen klären → 3. Claim ("ich nehm das") → 4. Bauen → 5. Push + ready-for-review → 6. Review vom anderen → 7. Merge → 8. README-Update

## 🔐 Security-Regel
Passwörter / API-Keys / Tokens = **Tabu im Chat + Repo.** Nur in `docs/credentials/` (lokal, verschlüsselt).
